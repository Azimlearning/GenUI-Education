# ideas.md — seed pool for Synapse v3

Raw seeds. Rough on purpose. The island structures them; see `island.md`.

Selection pressure declared 2026-08-19 by the author:
**real student use (KSSM Form 4/5) + engineering completeness. Competitions are not a factor.
Capacity: solo, heavy push, through late October 2026.**

## Syllabus library of ready labs
Every KSSM chapter opens instantly with an interactive lab that already exists, instead of a blank
box that costs 90 seconds and 19 cents to fill.

## Phone first
Most B40 and rural students revise on a phone, not a laptop. Right now the lab is designed desktop
out, phone in.

## Put the distilled router into production
The Keras student model exists and hits 88% on domain. It should be answering routing for free
instead of paying a model 1.5 seconds and real money for every question.

## Ground generation in the actual textbooks
1971 real KSSM passages are already ingested in ml/rag and nothing in the live pipeline uses them.

## Tutor loop
The learner drags a slider and nothing asks them why it moved.

## Remix an existing lab
"Add air resistance" without regenerating from scratch.

## SPM exam mode
Students study for one thing. Turn a past-year question into a lab, and turn a lab into an
SPM-style question with a marking scheme.

## Offline and downloadable
Artifacts are already self-contained HTML with local libraries. They could be saved and run with
no internet at all.

## Bahasa Melayu
SPM science papers are bilingual. The app is English only.

## Deploy it properly
Rate limits, a cost dashboard, a public URL. Nobody can use what is not running.

## Progress and revision history
Which concepts a student has actually explored, and what to revisit.

## Fix biology
Physics sims work. Biology is the weak domain and G11 is the acknowledged hardest case.

## Concept check inside the artifact
A two-question check before and after the interaction, so there is some evidence anyone learned
anything.

## Close the quality loop
Ratings and wrong-science flags should become regression evals automatically, so the system gets
more correct the more it is used.

## Run the evaluations that were deferred
The full 12-item golden set has never run and the hostile set has never run at all. Phase 1 and
Phase 2 definitions of done are therefore unmeasured.
